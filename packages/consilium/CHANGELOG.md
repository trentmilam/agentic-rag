# Changelog

## v1.0.0: initial release

- Core switchboard: router + integrity gate + composer; subject-routed, citation-bound answers, abstains when nothing supports the query.
- Integrity hardening: cross-corpus conflict detection with trust-tier resolution, corroboration-based poison quarantine.
- Heterogeneous routing across retrieval and compute modules; ships a Black-Scholes finance module as the reference compute capability.
- Generic compute adapters: third-party compute modules register from disk (`kind: "compute"`, opt-in via `allow_compute_adapters=True`).
